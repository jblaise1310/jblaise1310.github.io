Daily Fax Report

Run each morning to check the status of faxes sent the previous day. Any faxes showing Untransmitted must be verified and resent before they are considered processed.

When to run this: Every morning, before starting your queue. You are checking faxes sent the prior business day. Catching failed transmissions early prevents referral delays.

Step-by-Step Instructions

1
Open the DA2 App in Cerner
In Cerner, open the DA2 App. In the search field, type PROVIDER LETTER REPORT in the “type filter text” field.
DA2 App Icon
The DA2 app (P9984) as it appears in your Cerner app list.
2
Right-click PROVIDER LETTER REPORT → Run Report
Once located, right-click PROVIDER LETTER REPORT and select RUN REPORT. After running it once, the report saves to the Recent Reports tab on the left-hand menu for quick daily access.
Recent Reports Tab Location
After first use, find the report here each morning under Recent Reports.
3
Set the Date Range to the Prior Business Day
In the Discern Prompt dialog, set both Begin Date and End Date to yesterday's date. Then click Execute.
Date Range Prompt
Both fields should show the prior business day. Click Execute to run.
4
Review the Report for Untransmitted Faxes
Scan the STATUS column. Faxes showing Transmitted are complete. Any row showing Untransmitted requires action.
Report Output
Untransmitted rows are highlighted. Each one must be verified and resent.
5
Verify the Fax Number, Then Resend
For every Untransmitted fax, confirm the correct fax number before resending. Use any of these sources:
  • Review the fax number on the referral in Referral Management (RM)
  • Call the facility directly to verify
  • Check the HCF Spreadsheet for the facility's fax number on file
Once confirmed, resend by changing the referral status:
  • Change status from SENT back to Prep for Send
  • This re-routes the referral through the send process with the corrected number

Quick Reference Checklist

✍ Daily Fax Report Checklist

  • Open DA2 App in Cerner → search PROVIDER LETTER REPORT
  • Right-click → Run Report (or open from Recent Reports tab)
  • Set both date fields to prior business day → click Execute
  • Scan STATUS column for any Untransmitted rows
  • For each untransmitted fax: verify number via RM referral / facility call / HCF Spreadsheet
  • Change status SENT → Prep for Send to resend
Tip: After running the report once, use the Recent Reports tab in the DA2 left-hand menu each morning for one-click access. No need to search every day.
