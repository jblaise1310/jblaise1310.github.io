Report Request

Use the Report Request App in Cerner to compile and print multi-document packets for referrals. This allows you to pull clinic notes, radiology reports, and other records into a single PDF for the receiving provider.

When to use this: Any time you need to gather multiple documents from a patient's record and produce a single PDF to attach to or send with a referral.

Step-by-Step Instructions

1
Open the Report Request App in Cerner
In Cerner, locate and open the Report Request App. All fields highlighted in yellow are required and must be completed before you can proceed.
Report Request App Icon
The Report Request App (P9984) as it appears in Cerner.
2
Complete Subject Selection
In the Subject Selection tab, complete the following yellow required fields:
  • Change Report Scope to Cross-Encounter
  • Enter the patient's Last Name, First Name in the Name field
  • Click Search — a patient selection screen will appear
  • Confirm you have the correct patient, then Select that patient
Subject Selection Form
Set Report Scope to Cross-Encounter, enter the patient name, then Search.
3
Select the Documents to Include
In the center box, click on each document you want to include in the report. To select multiple documents at once, hold CTRL and click each document you need.
4
Complete the Release Details (Upper Right)
In the upper right section, complete the Release Details fields:
  • Purpose: Select Further Medical Care from the dropdown
  • Destination: Enter something in this field (an x is acceptable)
  • Requester: Enter something in this field (an x is acceptable)
Release Details
Purpose must be set to Further Medical Care. An "x" in Destination and Requester is sufficient.
5
Select Template and Document Types (Bottom Left)
In the bottom left section, it should default to the Template Selection tab. From the yellow dropdown, select Transition of Care – Ambulatory.
Template Selection
Select Transition of Care – Ambulatory from the template dropdown.

Then select all the document types that match what you selected above. The most commonly used types are:
Document You Need Select This Document Type
Clinic / Office Visit Notes CLINICAL DOC – Office-Clinic Notes
Radiology Reports RAD Diagnostic Radiology
6
Preview, Review, and Save as PDF
Once all document types are selected, click PREVIEW REPORT in the bottom right corner. Review the PDF to confirm the correct documents are included. Then:
  • Print to Microsoft Print to PDF
  • Save the file to your designated location for attachment to the referral

Quick Reference Checklist

✍ Report Request Checklist

  • Open Report Request App in Cerner
  • Set Report Scope to Cross-Encounter
  • Enter patient Last, First → Search → Select correct patient
  • Select documents in the center box (hold CTRL to multi-select)
  • Upper right: Purpose = Further Medical Care  |  Destination = x  |  Requester = x
  • Bottom left: Template = Transition of Care – Ambulatory
  • Select matching document types (Office-Clinic Notes, RAD Diagnostic Radiology, etc.)
  • Click PREVIEW REPORT → review → Print to Microsoft Print to PDF → Save
Tip: The Destination and Requester fields are required but the system accepts a placeholder entry. Entering x in both fields is the standard workaround when the fields do not apply.
