Dashboard Overview
A brief guide to your two tools  ·  Q1 2026

The provider 1:1 program now has two separate HTML files. Each is designed for a different moment in your workflow. This page gives you a quick reference for what each one does, what tabs it contains, and when to use it.

Both files open in any browser — no login, no installation. Just download and open. Charts load automatically as long as you have an internet connection.

📊
Shared with providers
PCC Provider 1:1 Dashboard
The main dashboard you use in meetings and post on the site. Designed to be viewed together with providers — everything in it is appropriate for them to see. Contains collective data, peer comparison tools, and individual provider reports.

What each tab does
☰ Collective Dashboard
The big picture. Shows overall visit volume, after-hours and message center burden, panel sizes, specialty encounter trends, surgical case comparisons, appointment wait times, and no-show totals — all as charts. Ends with the Director Analysis: three color-coded sections covering what is going well, what to monitor, and what needs action. Use this as a starting point for leadership discussions.
⇌ Provider Comparison
Side-by-side charts for all primary care providers — visits per day trends, after-hours trends, message center trends, EHR documentation time, no-shows, and a burnout risk composite score. Also includes a bubble chart plotting workload against after-hours burden. Use this to spot patterns across the group and identify outliers.
👥 Peer Benchmark
A privacy-respecting self-comparison tool. A provider selects their own name from a dropdown and sees their metrics highlighted alongside anonymized peers labeled Provider A, B, C. They can see exactly where they stand without seeing who the others are. Their own bars and lines appear in green; all peers appear in grey. Show this during individual interviews so providers can see their own context.
📋 Individual Reports
Click any provider name to open their full report — key indicator cards (next available appointment, next new patient slot, average visits per day), a monthly metrics table, four to six mini-charts, and their interview notes summary. A Print report button at the top lets you print a clean one-page handout to share with the provider during the meeting.

PCC Director View
Vicki's private prep tool. Contains everything needed to prepare for each individual 1:1 — forecasting, risk scores, data anomalies to be aware of, open action items, and suggested talking points. Never shown to providers directly.
jblaise1310.github.io/provider-reports/director-view.html
What it contains — per provider
🔎 Provider selector
Choose any provider from the dropdown — Primary Care, Specialty, or Behavioral Health. The full prep view populates instantly. A Print prep packet button at the top lets you print everything for that provider before the meeting.
📈 Burnout risk score
A composite score from 0 to 100 built from four weighted factors: after-hours EHR % (40%), message center % (25%), EHR documentation time (20%), and no-show rate (15%). Each factor shows as a bar so you can see what is driving the score. Color-coded: green is low risk, amber is moderate, red is high.
📊 Performance trends
Charts spanning Q4 2025 and Q1 2026 together — visits per day and after-hours across eight months so you can see the full trajectory, not just the most recent quarter.
🔁 Panel forecast
For providers with panels, shows actual panel size through April 2026 projected forward through October 2026 at the current monthly growth rate. Threshold lines mark the attention level and capacity concern level. For declining panels (RSM, Zappone) the chart shows the drop with a note explaining the concern.
📝 Items of note
Numbered flags Vicki needs to know before the interview — data anomalies (like the EHR formula error for certain providers), context notes (Mashburn returning from maternity leave), unresolved issues from prior interviews (Hintzman's February data distortion, Abbas's contract renewal), and anything that should not be presented to the provider without verification first.
✅ Open action items
A table of carry-forward action items from Q3 and Q4 2025 interviews, with current status (Completed, In Progress, Planned, Not Started), owner, and due date. Lets Vicki close the loop on prior commitments at the start of each interview.
💬 Conversation guide
Suggested talking points tailored to each provider's specific data patterns. Each point has a topic label and a suggested question in quotes. These are grounded in what the data actually shows — not generic check-in questions.

Quick reference — which file to use when
Before the interview
Open the Director View. Select the provider, review the burnout score and items of note, check open action items, read through the talking points. Print your prep packet.
During the interview
Open the Provider Dashboard. Go to Individual Reports, select the provider, and show them their report. Use the Peer Benchmark tab to show blinded comparison. Print their report to hand to them.
Leadership presentations
Use the Provider Dashboard, Collective tab. The Director Analysis at the bottom is written for leadership review. The charts are sized for screen sharing.
Posting to the site
The Provider Dashboard is live at provider-view.html. The Director View at director-view.html should be kept for Vicki only — do not share that link with providers.
